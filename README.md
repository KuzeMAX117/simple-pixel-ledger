# Trace Wallet 追溯钱包（Obsidian 插件）

Obsidian 月历可视化记账插件：日记里随手记，月历视图回溯查看历史收支流水，数据完全本地存储。金额数字使用 **Press Start 2P 像素字体**（已内嵌，OFL 开源协议）。

## 功能

- **记录**：分类、明细、金额、描述四项，支出/收入一键切换。
- **组合框下拉**：点击「分类/明细」弹出下拉框，直接点选常用项，也可输入新内容；分类列表随「支出/收入」自动切换。
- **常用预设**：支出分类、收入分类、明细、金额快捷按钮在「设置 → 追溯钱包」里交互式管理——＋添加、×删除、恢复默认，改动立即生效并同步刷新所有界面。
- **自动汇总**：任意面板自动计算当日/当月总额（支出、收入、结余）。
- **三种入口**：
  1. 日记内嵌面板（代码块，自动识别日记文件名日期）；
  2. 独立月历统计视图（类似 TODO 侧边栏，可固定右侧，也可拖到主面板 Tab）；
  3. 快速记账弹窗（任意位置补录历史日期）。
- **月历视图**：红 = 支出/负收入，绿 = 收入/正收入，格子内直接显示金额，点击任意日期查看当日明细，可前后翻月、一键回今天。
- **分组折叠明细**：收支明细默认只显示「支出 / 收入」两个分组标题（含笔数与合计），点击展开具体条目、再点折叠，记录再多也不遮挡快速记账区；展开状态在删除后保持。

## 安装

1. 把插件放入你的库目录：`你的库/.obsidian/plugins/trace-wallet/`（文件夹名必须是 `trace-wallet`，没有 `plugins` 文件夹就新建）。
2. 打开 Obsidian → 设置 → 第三方插件 → 关闭「安全模式」→ 启用 **追溯钱包**。
3. 侧边栏出现「¥」图标即为独立视图；命令面板（Ctrl+P）里搜「追溯钱包」可调用全部命令。

> 需要已安装的 Obsidian 版本 ≥ 1.4.0。

## 使用

| 操作 | 方式 |
|---|---|
| 打开月历统计视图 | 点击左侧「¥」图标，或命令面板「打开追溯钱包」 |
| 在日记里插入收支面板 | 命令面板「在笔记中插入今日收支面板」，或直接在笔记里写： |
| | ```` ```trace-wallet ```` |
| | ```` ``` ```` |
| 面板指定日期 | 代码块内加 `date: 2026-10-29`（不写则自动取日记文件名里的日期，取不到就用今天） |
| 快速记一笔 | 命令面板「快速记一笔收支（弹窗）」，弹窗里可改日期补录 |
| 修改常用预设 | 设置 → 追溯钱包 → ＋添加 / ×删除 / 恢复默认，立即生效 |
| 删除一条记录 | 明细条目右侧 × 按钮 → 弹出确认框（显示该笔金额/分类/日期），确认后才删除 |
| 清空全部记录 | 设置 → 追溯钱包 → 数据管理（保留预设） |

> 旧版代码块标签 `pixel-ledger` 仍兼容渲染，已有日记无需改动。

数据保存在 `你的库/.obsidian/plugins/trace-wallet/data.json`，随库同步/备份。

## 开发

```bash
npm install
npm run build   # 类型检查 + 打包 main.js
npm run dev     # watch 模式
```

## 文件说明

- `main.ts` 插件入口：命令、设置页（交互式预设管理）、视图注册
- `ledger-view.ts` 独立月历统计视图
- `ledger-block.ts` 日记代码块渲染
- `ledger-modal.ts` 快速记账弹窗
- `shared.ts` 共享 UI（表单/列表/汇总条/格式化）
- `combo.ts` 组合框组件（点击弹下拉、可点选可输入）
- `store.ts` 数据结构与工具函数
- `styles.css` 像素风样式（内嵌 Press Start 2P 字体，OFL）
- `demo.html` 独立界面预览（示例数据）
